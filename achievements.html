Learning Outcomes

教学卡片 1-3 学习成果

这一页整理我在前三张教学卡片中的学习收获：从建立数字基础设施，到学会指挥 AI，再到理解 API、RAG 和工作流。

我的 AI 学习过程 学习成果记录 fangjiaguode@gmail.com
01

教学卡片 1

打开那扇门

核心是建立与世界接轨的数字基础设施，包括科学上网、海外账号、浏览器插件、网络检测工具和国际支付认知。

  • 理解 VPN 的本质是流量加密转发。
  • 注册 Gmail、YouTube、GitHub、OpenAI、X 等账号。
  • 开始理解账号、节点、IP、支付方式这些基础概念。
02

教学卡片 2

认识你的新同事

核心是了解 AI 工具体系，掌握和 AI 协作的表达方式，从普通提问升级到结构化指令。

  • 理解 AI 不是搜索引擎，而是可以被指挥的工具。
  • 学习提示词、Markdown、JSON 等基础表达方式。
  • 接触 GitHub、Notion、Obsidian，建立知识管理意识。
03

教学卡片 3

让 AI 替你动手做东西

核心是从“使用 AI”走向“调用 AI”，开始理解 HTTP 请求、API、多模态生成、工作流和知识库。

  • 学习用 API 理解客户端和服务器之间的对话。
  • 了解音频、视频、Q 版形象等多模态内容生成。
  • 理解 ComfyUI、RAG、向量空间和知识库的底层思路。

Deep Summary

三张卡片的递进逻辑

这三张卡片不是单纯教某个工具，而是在一步步训练“数字世界的基础能力”。 第一张解决能不能进入全球信息环境，第二张解决能不能正确指挥 AI，第三张解决能不能通过 API 和工作流让 AI 真正动手做事。

基础设施 科学上网、账号、支付、浏览器插件
人机协作 提示词、Markdown、JSON、知识管理
自动化调用 HTTP 请求、API、RAG、节点工作流

My Takeaway

我的阶段性收获

我开始明白：AI 编程学习不是一下子写出很复杂的程序，而是先搭好账号、工具、知识库和网页，再用 AI 帮我拆解任务、生成代码、解释错误和持续优化。
